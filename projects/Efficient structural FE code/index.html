Efficient C++ structural FE code

A lightweight, high-performance 2D 4-node quad linear (full integration) structural solver built from scratch.

C++23 Eigen library Intel MKL OpenMP

1. Project Goals

  • Transition from Prototype to Production Code: Evolve an initial MATLAB FE code (static/dynamic linear and non-linear) into a compiled, high-performance C++ implementation.
  • Eliminate Overhead: Design a lightweight solver core optimized for raw speed on standard 2D quad elements (full $2\times2$ integration) without commercial software bloat.

2. Methodology & Implementation

  • Element Formulation: Coded a 2D 4-node isoparametric quadrilateral element using full $2\times2$ Gauss quadrature integration.

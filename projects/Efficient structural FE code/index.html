Efficient C++ structural FE code

A lightweight, high-performance 2D quad linear (full integration) structural solver built from scratch.

C++23 Eigen library (matrix/vector manipulation and operations) Intel oneMKL (linear solver) OpenMP (multi-threading) CMake (simplifying code-compiling process) MATLAB

1. Project Goals

  • Deriving the weak formulation of solid mechanics PDEs (momentum, strain-displacement and constitutive eq.) using the Galerkin method, for geometric linear and non-linear (Total Lagrangian formulation) problems, both static and implicit-dynamic (Newmark-beta time integration).
    • Starting from a 2D domain discretized by 4-node full integration quadrilateral isoparametric elements develop:
  • Mesh import + set BC + set IC.
  • Global stiffness (and mass) matrix assembly, being as memory efficient as possible.
  • Newton-Raphson loop for non-linear problems, after deriving the effective stiffness matrix.
  • Integrate state of the art linear solver.
  • Export the results in .vtk format to visualize and post-process the results in ParaView.

2. Implementation

    Starting from MATLAB (using Procedure Oriented Programming):
  • Automatic mesh and BC-nodes import from Abaqus .inp file and SALOME .dat file.
  • Checking for highly distorted elements via Jacobian ratio.
  • Setting material properties and plane stress/strain assumption.
  • Setting Boundary Conditions and Initial Conditions (possibility to start dynamics from a static solution).
  • Using a sparse global stiffness (and mass) matrix, defined through a list of triplets [i,j,val].
  • Time integration using Newmark-beta method (dynamics).
  • In case of geometric non-linearity (potentially material and BC non-linearity as well), computing the internal force vector and effective tangent stiffness matrix, solving for the next best displacement vector and iterating until the normalized residual of the equilibrium equations is lower than threshold.
  • Write an ASCII .vtk file containing the results (stress tensor and displacement field).

    • Passing to C++ (OOP and POP) to achieve higher efficiency.
    The implementation is similar to what was done in MATLAB but with efficiency in mind:
  • Using Eigen template library to make matrix manipulation and operations highly efficient, thanks to lazy evaluation (compile-time simplifications) and SIMD optimization.
  • Using .reserve() to avoid dynamic memory reallocations of std::vectors.
  • Using stack operations with std::vectors and std::strings.
  • Passing non-trivial method arguments by address or reference.
  • Allowing compiler optimizations (-O3).
  • Using constexpr (objects defined at compile-time/priori) whenever possible.
  • Allowing the user to choose between single and double precision from "settings" file.
  • Integrating via Eigen wrapper the state of the art linear direct solver Intel PARDISO.
  • Allowing the user to choose between binary (more efficient) and ASCII .vtk file to store the results.
  • Allowing the user to choose between single-thread and multi-thread execution (OpenMP).

3. Results

Current Development Status:

  • Custom MATLAB code: Currently restricted to 2D quad elements (full integration).
    • Linear static solver
    • Implicit dynamic linear solver
    • Implicit dynamic non-linear solver
  • Custom C++ Engine: Currently restricted to 2D quad elements (full integration).
    • Linear static solver (single and multi-thread execution)
    • Implicit dynamic solvers (in development)

A static linear analysis benchmark was conducted across Abaqus Standard, custom C++ solver and custom MATLAB solver.

Details of the model:

  • Geometry: a quarter of a 200x100x2 mm plate with a hole of diamter 20 mm in the centre.
  • Material Properties: isotropic linear elastic (E = 200 GPa, nu = 0.3)
  • Solver Options: static, no geometric non-linearity, double precision, direct linear solver.
  • Solver Outputs: nodal displacements and stress tensor withing the solid domain.
  • Mesh: structured quad mesh of linear (4-node) quadrilateral full integration (4 integration points) plane stress elements: 210316 elements and 211279 nodes.
  • BC and load: fixed the nodal displacements (perpendicular to the edge) at the symmetry edges, 10 kN applied to the free vertical edge.

Below are summarised the benchmark results:

Metric custom MATLAB code Abaqus/Standard Custom C++ code
